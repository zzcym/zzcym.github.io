让静态页面动起来：六个可以抄走的小把戏

纯 HTML 与 CSS 能做到的事情，比你以为的多得多。

你看到的每一个演示，都是它真正的样子——没有录屏，没有 GIF，只有 HTML 和一点点 JavaScript。

很多人以为“静态网站”等于“不会动”。其实浏览器在这十年里悄悄变成了一个相当强的动画引擎：clip-path 能裁出任意形状，IntersectionObserver 知道元素什么时候进入视野，canvas 可以把每个像素都当成颜料。

下面这几样，全部来自这个站点本身。喜欢哪个就整段拿走。

01 / 文字解码

鼠标划过去，文字像被重新解码一样抖一下。核心只有一句话：在每一个字符位置随机换字，越靠前的字符越早停下来。

01 hover me
THE QUIET PART OF THE WEB 
out += p > (i / len) * 0.85 ? target[i] : GLYPHS[random()];

02 / 磁吸按钮

鼠标靠近时，按钮朝光标方向轻轻挪几个像素；离开时回弹。位移只有 8–10px，刚好能被感觉到，又不会让人觉得按钮“跑了”。

02 靠近试试
el.style.transform = `translate(${dx * 10}px, ${dy * 8}px)`;

03 / 光标聚光

用一个跟着光标走的径向渐变，把注意力压在鼠标附近。适合放在一整块很静的页面上，让“空”也有内容。

一道很轻的光 
background: radial-gradient(200px 200px at var(--sx) var(--sy),
                    rgba(255, 90, 54, .16), transparent 70%);

04 / 点击爆散

四十六个方形粒子，带一点重力，用 canvas 画。没有粒子库，一共三十行。

点一下这里 
p.vy += 0.12; p.vx *= 0.985;
        p.x += p.vx; p.y += p.vy;
        ctx.fillRect(p.x, p.y, p.s, p.s);

05 / 倾斜卡片

鼠标在卡片上移动时，它会朝你倾斜一点；卡片里的文字用 translateZ 浮在不同的层上，靠近时会有纵深。

card / 01
会跟着你转的卡片
关键是 perspective 要和 rotateX / rotateY 一起给，再加一个 preserve-3d。
transform: perspective(760px) rotateY(12deg) rotateX(-8deg);

06 / 渐变动字

把一段渐变塞进文字里，然后让背景慢慢移动。因为 background-clip: text，你能看到的只有字本身。

Light moves slowly.
background: linear-gradient(100deg, #4a4640, #f1ece2, #ff5a36, #f1ece2, #4a4640);
        background-clip: text; color: transparent;
        animation: shimmer 6s linear infinite;

最后一句

这些效果有一个共同点：它们都只发生一次，或者只跟着鼠标走很短的一段。真正让人难受的不是动效太少，而是动效太多——每个元素都在争着说话，页面就变成了噪音。

我的原则是：一屏之内，最多一个主动画的元素。剩下的，交给留白和一点点时间。
